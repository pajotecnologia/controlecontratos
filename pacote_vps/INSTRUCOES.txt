==================================================
INSTALACAO NA VPS COM aaPanel + PostgreSQL
==================================================

Requisitos (instalar via App Store do aaPanel se ainda nao tiver):
- Node.js (v18 ou superior) -> App Store > "Node.js version manager"
- PM2 Manager -> App Store > "PM2 Manager" (gerencia o processo Node)
- PostgreSQL (v13+) -> ja instalado
- Nginx -> ja vem com o aaPanel (usado para o proxy reverso)

--------------------------------------------------
PASSO 1 - CRIAR O BANCO DE DADOS
--------------------------------------------------
Opcao A (pelo painel):
   - Menu "Databases" > selecione PostgreSQL > "Add Database"
   - Nome do banco: controle_comissoes
   - Anote o usuario e a senha gerados.

Opcao B (pelo terminal do aaPanel, menu "Terminal"):
   sudo -u postgres psql -c "CREATE DATABASE controle_comissoes;"

--------------------------------------------------
PASSO 2 - ENVIAR OS ARQUIVOS
--------------------------------------------------
   - Menu "Files" > entre em /www/wwwroot/
   - Crie a pasta: controle_comissoes
   - Faca upload de TODOS os arquivos desta pasta (pacote_vps) para
     /www/wwwroot/controle_comissoes
     (pode compactar em .zip, subir e usar "Unzip" no painel)

Estrutura final esperada em /www/wwwroot/controle_comissoes:
   public/  auth.js  contratos.js  db.js  index.js  init-db.js
   notifications.js  query.js  banco.sql  package.json  .env.example

--------------------------------------------------
PASSO 3 - CONFIGURAR O .env
--------------------------------------------------
   - No menu "Files", entre na pasta do projeto.
   - Copie .env.example para .env (botao direito > Copy, renomeie para .env)
   - Edite o .env com os dados reais:

   DATABASE_URL="postgresql://USUARIO:SENHA@localhost:5432/controle_comissoes"
   DATABASE_SSL="false"
   JWT_SECRET="COLE_AQUI_UMA_CHAVE_ALEATORIA_LONGA"
   PORT=3001
   PUBLIC_URL="http://SEU_DOMINIO_OU_IP"

   ATENCAO - CONFLITO DE PORTA:
   Voce ja tem outro sistema usando a porta 3000. Por isso este projeto
   usa a porta 3001. Antes de subir, confirme que a 3001 esta livre:
        ss -tlnp | grep 3001
   Se NAO retornar nada, a porta esta livre. Se retornar algo, escolha
   outra porta (ex: 3002, 4000, 8080), coloque no PORT do .env e use o
   mesmo numero no Target URL do proxy reverso (Passo 6).

   Gerar um JWT_SECRET seguro (menu Terminal):
   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

--------------------------------------------------
PASSO 4 - INSTALAR DEPENDENCIAS E CRIAR TABELAS
--------------------------------------------------
   No menu "Terminal" do aaPanel:
   cd /www/wwwroot/controle_comissoes
   npm install
   npm run init-db     (cria todas as tabelas a partir do banco.sql)

--------------------------------------------------
PASSO 5 - SUBIR O APP COM PM2
--------------------------------------------------
Opcao A (PM2 Manager pelo painel):
   - Abra "PM2 Manager" > "Add Project"
   - Project directory: /www/wwwroot/controle_comissoes
   - Startup file / entry: index.js
   - Salve e inicie.

Opcao B (terminal):
   cd /www/wwwroot/controle_comissoes
   pm2 start index.js --name controle-comissoes
   pm2 save

   O backend estara rodando na porta 3001 (definida no .env).
   O frontend ja compilado (pasta public) e servido pelo proprio Node.

--------------------------------------------------
PASSO 6 - PROXY REVERSO (acessar pelo dominio/porta 80)
--------------------------------------------------
   - Menu "Website" > "Add site" > informe seu dominio (ou o IP).
   - Apos criar, entre no site > aba "Reverse Proxy" > "Add reverse proxy":
        Proxy name: controle
        Target URL: http://127.0.0.1:3001
        Send Domain: $host
   - Salve. Agora o acesso pelo dominio na porta 80/443 cai no app.
   - (Opcional) Ative SSL gratis em "SSL" > "Let's Encrypt".

--------------------------------------------------
OBSERVACOES
--------------------------------------------------
   - Uploads sao salvos automaticamente numa pasta "uploads" criada pelo app.
   - Se mudar a PORT no .env, ajuste tambem o Target URL do proxy reverso.
   - Para ver logs: PM2 Manager > logs, ou no terminal: pm2 logs controle-comissoes
   - Para reiniciar apos mudar o .env: pm2 restart controle-comissoes
